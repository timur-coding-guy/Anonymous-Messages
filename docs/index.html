Send messages without revealing your identity

A Telegram bot that lets you send anonymous messages through unique links. Message content is never stored.

To use this bot, you need to host it yourself with your own Telegram bot token and database.

Hashed user IDs

Your Telegram ID is hashed with SHA-256 and salt before storage, rather than stored directly.

No message storage

Messages pass through Telegram's servers directly. Your database never stores message content or metadata.

Multi-language support

Available in English, Russian, and Ukrainian.
